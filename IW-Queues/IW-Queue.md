# Fila de escrita incremental

## Como usar a fila

1. Escolha um projeto por sessão e abra o ponto em que parou.
2. Faça um avanço pequeno e verificável: acrescentar um parágrafo, integrar uma ideia de um Zettel ou reorganizar uma seção.
3. Ao terminar, registre no próprio projeto o próximo passo concreto. Isso reduz o custo de retomada na próxima sessão.
4. Mantenha os projetos ativos marcados com `#escrita` para aparecerem no [[meta/dataview/dashboard-ir-srs|painel de estudo]].
