# Plugins candidatos para o vault

Lista de possibilidades para avaliar antes de instalar. O objetivo é acrescentar fluidez ao fluxo de pesquisa, escrita e rotina, evitando duplicar ferramentas que o vault já usa.

## Direção do fluxo
- Os PDFs permanecem no Zotero.
- Plugins de IA/MCP devem ser restritos ao loopback e com permissões granulares.
- Priorizar plugins que melhorem a visualização de nexos historiográficos e cronologias.

## Lista de Candidatos

| Plugin | Uso possível no vault | Referência |
|---|---|---|
| **Various Complements** | Completar termos recorrentes enquanto se escreve. | [Página oficial](https://community.obsidian.md/plugins/various-complements) |
| **Excalidraw** | Criar mapas conceituais e diagramas de atores. | [Página oficial](https://community.obsidian.md/plugins/obsidian-excalidraw-plugin) |
| **ExcaliBrain** | Explorar relações entre Zettels como mapa navegável. | [Página oficial](https://community.obsidian.md/plugins/excalibrain) |
| **Hover Editor** | Abrir prévia editável de nota ao passar sobre link. | [Página oficial](https://community.obsidian.md/plugins/obsidian-hover-editor) |
| **Unified Outliner** | Navegar por títulos e listas como estrutura única. | [Página oficial](https://community.obsidian.md/plugins/unified-outliner) |
| **Meridian Timeline** | Montar cronologias navegáveis de notas de eventos. | [Página oficial](https://community.obsidian.md/plugins/meridian-timeline) |
| **Live Canvas** | Gerar mapa Canvas sincronizado a partir de pastas/tags. | [Página oficial](https://community.obsidian.md/plugins/live-canvas) |
| **Timeline Canvas** | Comparar processos históricos em faixas paralelas. | [Página oficial](https://community.obsidian.md/plugins/timeline-canvas) |
| **Better Backlinks** | Consultar parágrafos completos das notas que citam um Zettel. | [Página oficial](https://community.obsidian.md/plugins/better-backlinks) |
